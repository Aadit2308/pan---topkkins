# Human-Activity-Recognition-using-Smartphone-Sensors
Human Activity Recognition (HAR) is a machine learning application that identifies a person's physical activity—such as walking, running, sitting, standing, or climbing stairs—using data from a smartphone's built-in accelerometer and gyroscope. The sensor signals are first preprocessed using digital signal processing techniques like filtering, segmentation, and feature extraction (e.g., mean, variance, FFT-based frequency features). These processed features are then used to train a machine learning model, such as a Random Forest, CNN, or LSTM, to classify the user's activity in real time. HAR has applications in fitness tracking, healthcare monitoring, fall detection, and smart wearable systems
